# MdirWin — mdir デスクトップ版（Windows）

mdir（2ペインファイルマネージャー）の Windows ネイティブデスクトップ版。
WPF によるネイティブ UI で、2ペインはターミナルエミュレータではなくネイティブのリストビューとして実装しています。

## 画面構成

```
┌──────────────┬───────────────┬───────────────┬──────────────┐
│ 左サイドバー   │   左ペイン      │   右ペイン      │ 右サイドバー   │
│ ・フォルダツリー│                │               │ ・フォルダツリー│
│  （左ペイン用）│                │                │  （右ペイン用）│
│ ・コピー元     │                │                │              │
│ ・コピー先     │                │                │              │
├──────────────┴───────────────┴───────────────┴──────────────┤
│ ステータスバー（アクティブペインのパス / ⎇ ブランチ / コマンドライン）│
└──────────────────────────────────────────────────────────────┘
```

- 左のツリーは**左ペイン**、右のツリーは**右ペイン**に対応。ツリーのフォルダをクリックすると対応するペインが移動し、ペインの移動に合わせてツリーも自動展開されます。
- 各ペインの下部とウィンドウ最下部に Git ブランチ名（⎇）を表示します。

## キーバインド（アプリがアクティブなときのみ）

### ナビゲーション

| キー | 動作 |
|------|------|
| `h` / `←` / `BS` | 親フォルダへ移動 |
| `j` / `↓` | カーソルを下に移動 |
| `k` / `↑` | カーソルを上に移動 |
| `l` / `→` / `Enter` | フォルダに入る / ファイルを開く |
| `g` / `Home` | 先頭へジャンプ |
| `G` / `End` | 末尾へジャンプ |
| `PgUp` / `PgDn` | ページ単位で移動 |
| `~` | ホームフォルダへ移動 |
| `Tab` | アクティブペインを切り替え |

### ファイル操作

| キー | 動作 |
|------|------|
| `c` / `F5` | 反対ペインへコピー |
| `m` / `F6` | 反対ペインへ移動 |
| `d` / `F8` / `Del` | 削除（ゴミ箱へ移動） |
| `r` / `F2` | 名前の変更 |
| `n` / `F7` | 新規フォルダ作成 |
| `t` / `F4` | 新規ファイル作成 |
| `Space` / `Ins` | マーク / マーク解除 |
| `a` | 全マーク / 全解除 |
| `s` | ソートメニュー |
| `.` | 隠しファイル表示切り替え |
| `i` | ファイル情報 |
| `y` | Git Pull（リポジトリ内のみ） |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | クリップボード（エクスプローラー互換） |
| `Ctrl+R` | 最新の情報に更新 |

マークされたファイルがあれば、コピー・移動・削除はマークされたファイル全体が対象になります。

### コマンドモード

`:` を入力するとウィンドウ下部にコマンドラインが開きます。

| コマンド | 動作 |
|----------|------|
| `:help` | ヘルプを表示 |
| `:q` / `:quit` | 終了 |
| `:cd <パス>` | フォルダ移動（`~` はホーム） |
| `:sort <基準>` | ソート（name / size / date / ext） |
| `:find <文字列>` | ファイル名検索（`o` 前へ / `p` 次へ） |
| `:mkdir <名前>` | フォルダ作成 |
| `:touch <名前>` | ファイル作成 |
| `:!<コマンド>` | シェルコマンド実行（結果を別ウィンドウ表示） |

### グローバルショートカット（他のアプリを使用中でも有効）

| キー | 動作 |
|------|------|
| `Win+Ctrl+Shift+[` | コピー元 → コピー先 へ全ファイルを強制上書きコピー |
| `Win+Ctrl+Shift+]` | コピー先 → コピー元 へ全ファイルを強制上書きコピー |

グローバルなのはこの2つだけで、他のキー操作はアプリがアクティブなときのみ有効です。
実行結果は画面右下のトースト通知で表示されます。

## サイドバーのツリー右クリックメニュー

サブフォルダの作成 / フォルダ名の変更 / フォルダの削除（ゴミ箱） /
フォルダのコピー / フォルダ名のコピー / フォルダのフルパスのコピー /
コピーしたフォルダまたはファイルの貼り付け

## ビルド

.NET 8 SDK が必要です。

```powershell
cd winapp

# テスト
dotnet test MdirWin.Core.Tests\MdirWin.Core.Tests.csproj

# 開発ビルド・実行
dotnet run --project MdirWin\MdirWin.csproj

# 配布用（自己完結・単一 exe → dist\MdirWin.exe）
dotnet publish MdirWin\MdirWin.csproj -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true `
  -p:EnableCompressionInSingleFile=true -o dist
```

## プロジェクト構成

```
winapp/
├── MdirWin.sln
├── MdirWin/                  # WPF アプリ本体
│   ├── MainWindow.xaml(.cs)  # メインウィンドウ（キールーティング・コマンドモード）
│   ├── GlobalHotkeys.cs      # RegisterHotKey によるグローバルショートカット
│   ├── ProcessRunner.cs      # 外部コマンド実行（git pull / :!）
│   ├── AppConfig.cs          # 設定の保存（%APPDATA%\MdirWin\config.json）
│   ├── Controls/
│   │   ├── FilePaneControl   # ファイルペイン（カーソル・マーク・ソート・検索）
│   │   ├── FolderTreeControl # サイドバーのフォルダツリー
│   │   ├── FileEntry.cs      # 行の表示モデル（マーク状態含む）
│   │   └── ClipboardHelper.cs# エクスプローラー互換クリップボード
│   └── Dialogs/              # 入力・出力・トースト通知
├── MdirWin.Core/             # UI 非依存ロジック
│   ├── FileOperations.cs     # ミラーコピー・コピー・移動・一意名生成
│   └── GitHelper.cs          # .git/HEAD からブランチ名を取得
└── MdirWin.Core.Tests/       # xUnit テスト
```

## 設定の保存場所

ペインの表示フォルダ、コピー元/コピー先フォルダは終了時に
`%APPDATA%\MdirWin\config.json` に保存され、次回起動時に復元されます。
