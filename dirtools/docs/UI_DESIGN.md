**バージョン:** 0.1.0
**作成日:** 2026-02-11
**対応要件:** REQUIREMENTS.md
**ステータス:** ドラフト

---

## 1. 設計方針

### 1.1 UIコンセプト
- **vi-first**: viエディタのモード・操作体系を基盤とし、viユーザーが自然に使えるUI
- **Mouse-ready**: キーボード主軸だが、マウスでも全操作が完結するモダンなインタラクション
- **Information-dense**: 限られたターミナル領域に最大限の情報を効率的に配置
- **Distraction-free**: 操作に集中できるミニマルなデザイン、必要な情報だけを適切なタイミングで表示

### 1.2 最小ターミナルサイズ
| 項目 | 値 |
|---|---|
| 最小幅 | 80カラム |
| 最小高さ | 24行 |
| 推奨幅 | 120カラム以上 |
| 推奨高さ | 40行以上 |

80x24未満の場合はリサイズを促す警告メッセージを表示する。

## 2. 画面構成

### 2.1 レイアウト領域定義

画面は垂直方向に以下の5領域で構成される。各領域は固定行数または可変行数を持つ。

```
行数   領域
─────────────────────────────────────
 1     ┌─ ヘッダーバー ──────────────┐    固定 1行
 1     ├─ パスバー ──────────────────┤    固定 1行（各ペインに1行）
 n     ├─ ファイルペイン領域 ─────────┤    可変（残り全行を使用）
 1     ├─ ステータスバー ────────────┤    固定 1行
 1     └─ ファンクションバー ────────┘    固定 1行
─────────────────────────────────────
合計: 4行（固定）+ n行（可変）= ターミナル高さ
```

### 2.2 各領域の座標定義

```
y=0   ┌──────────────────────────────────────────────────────────────┐
      │ HEADER BAR                                                    │
y=1   ├─────────────────────────────┬────────────────────────────────┤
      │ PATH BAR (LEFT)             │ PATH BAR (RIGHT)               │
y=2   ├─────────────────────────────┼────────────────────────────────┤
      │                             │                                │
      │  FILE PANE (LEFT)           │  FILE PANE (RIGHT)             │
      │                             │                                │
      │                             │                                │
      │                             │                                │
y=H-2 ├─────────────────────────────┴────────────────────────────────┤
      │ STATUS BAR                                                    │
y=H-1 ├──────────────────────────────────────────────────────────────┤
      │ FUNCTION BAR                                                  │
y=H   └──────────────────────────────────────────────────────────────┘
      x=0                      x=W/2                               x=W
```

- `H` = ターミナル高さ（行数）
- `W` = ターミナル幅（カラム数）
- ペイン境界: デフォルト `x = W/2`（ドラッグで変更可能、最小幅20カラム）

## 3. ウィジェット仕様

### 3.1 ヘッダーバー (HeaderBar)

```
┌──────────────────────────────────────────────────────────────────────┐
│ [Tab1] [Tab2] [Tab3]                            branch:main mdir v0.1│
└──────────────────────────────────────────────────────────────────────┘
```

| 要素 | 位置 | 内容 | スタイル |
|---|---|---|---|
| タブリスト | 左寄せ | `[TabN]` 形式で並列表示 | アクティブ: Bold+反転 / 非アクティブ: Dim |
| Gitブランチ | 右寄せ | `branch:<name>` | シアン |
| アプリ名+バージョン | 右端 | `mdir v0.1` | Dim |

- **マウス操作:** タブ部分をクリックでタブ切り替え
- **Phase 1:** タブは1つのみ（タブ表示なし）。右端にアプリ名のみ表示

### 3.2 パスバー (PathBar)

```
├──────────────────────────────┬───────────────────────────────────────┤
│ 📁 ~/projects/myapp          │ 📁 ~/projects/myapp/src              │
├──────────────────────────────┼───────────────────────────────────────┤
```

| 要素 | 内容 | スタイル |
|---|---|---|
| ディレクトリアイコン | `📁` (Unicode) | — |
| パス文字列 | カレントディレクトリの絶対パス | アクティブ: Bold白 / 非アクティブ: Dim |

- ホームディレクトリは `~` に短縮表示
- パスが長い場合は先頭を `...` で省略: `📁 .../very/deep/path`
- **マウス操作:** パスバーをクリックでそのペインをアクティブ化

### 3.3 ファイルペイン (FilePane)

#### 3.3.1 カラム構成

```
│ ■ Name               Size     Date     │
│ ────────────────────────────────────── │
│   ..                                    │
│ ▶ src/               4.2KB    02/11     │
│   tests/             1.1KB    02/10     │
│ ● Cargo.toml         512B     02/11     │
│   README.md          2.3KB    02/09     │
```

| カラム | 幅 | 内容 | 配置 |
|---|---|---|---|
| マークインジケータ | 2文字 | `●`(マーク) / `▶`(カーソル) / ` `(なし) | 左 |
| ファイル名 | 可変（残幅） | ファイル/ディレクトリ名 | 左寄せ |
| サイズ | 8文字 | 人間可読形式 (B/KB/MB/GB) | 右寄せ |
| 更新日時 | 8文字 | `MM/DD` or `HH:MM`（当日の場合） | 右寄せ |

#### 3.3.2 ファイル名表示ルール
- ディレクトリ名の末尾に `/` を付与
- シンボリックリンクは `→ <target>` を追記
- ファイル名が表示幅を超える場合は末尾を `~` で切り詰め

#### 3.3.3 カーソル行のスタイル
| 状態 | 背景色 | 文字色 |
|---|---|---|
| カーソル行（アクティブペイン） | DarkBlue (#1a1b26) | White Bold |
| カーソル行（非アクティブペイン） | DarkGray (#333333) | White |
| マーク済み行 | なし | Yellow Bold |
| カーソル行 + マーク済み | DarkBlue | Yellow Bold |

#### 3.3.4 スクロール
- ファイル数がペイン高さを超えた場合、仮想スクロールを実施
- カーソルが画面外に出る場合、自動スクロール
- スクロール余白: 上下3行（カーソルがこの範囲に入ったらスクロール開始）
- 右端にスクロールインジケータ（`▲`/`▼`）を表示

#### 3.3.5 ペイン境界
| 状態 | 線種 | 色 |
|---|---|---|
| アクティブペイン | `│` (太線/Bold) | White |
| 非アクティブペイン | `│` (細線) | DarkGray |

- **マウス操作:** 境界線をドラッグでペイン幅を変更（最小20カラム）

### 3.4 ステータスバー (StatusBar)

```
├──────────────────────────────────────────────────────────────────────┤
│ Cargo.toml │ 512B │ 2026-02-11 14:30 │ -rw-r--r-- │ Modified      │
├──────────────────────────────────────────────────────────────────────┤
```

| セグメント | 内容 | 区切り |
|---|---|---|
| ファイル名 | カーソル位置のファイル名 | `│` |
| サイズ | 正確なサイズ表示 | `│` |
| タイムスタンプ | `YYYY-MM-DD HH:MM` 形式 | `│` |
| パーミッション | Unix形式 `-rwxr-xr-x` | `│` |
| Gitステータス | Modified / Untracked / Staged 等 | — |

- **マーク時:** `3 files selected (12.5KB)` のように選択サマリーを表示
- 背景色: DarkCyan / 文字色: Black

### 3.5 ファンクションバー (FunctionBar)

```
├──────────────────────────────────────────────────────────────────────┤
│ [F2]Ren [F5]Copy [F6]Move [F8]Del [:]Cmd [:help]Help [q]Quit       │
└──────────────────────────────────────────────────────────────────────┘
```

| 要素 | スタイル |
|---|---|
| キー部分 `[F2]` | Bold + 黒背景に白文字 |
| ラベル部分 `Ren` | 通常文字（Dim） |

- **マウス操作:** 各ボタンをクリックで対応するアクションを実行
- ファンクションバーは常に表示（コマンドモード時は非表示、コマンド入力行に置き換え）

## 4. モード別UI仕様

### 4.1 ノーマルモード (Normal Mode)

**デフォルト状態。** 全ウィジェットが通常表示される。

- 全キーバインドがアクティブ
- マウスイベントを全領域で受け付ける
- ファイルペインにフォーカス

### 4.2 コマンドモード (Command Mode)

`:` キー入力で遷移。ファンクションバー行がコマンド入力行に置き換わる。

```
├──────────────────────────────────────────────────────────────────────┤
│ :█                                                          [Back]  │
└──────────────────────────────────────────────────────────────────────┘
```

#### コマンド入力行 (CommandLine) ウィジェット仕様

| 要素 | 位置 | スタイル |
|---|---|---|
| プロンプト `:` | 左端(x=1) | Bold White |
| 入力テキスト | プロンプトの右 | White |
| カーソル | テキスト末尾 | 反転ブロックカーソル `█` |
| `[Back]` ボタン | 右端(右寄せ) | Dim（ホバー時: Bold） |

#### オートコンプリートのポップアップ

```
├──────────────────────────────────────────────────────────────────────┤
│ :he█                                                        [Back]  │
│ ┌─────────┐                                                          │
│ │ help    │ ← 候補リスト（コマンド入力行の上に表示）                     │
│ └─────────┘                                                          │
```

- コマンド入力行の**上方向**にポップアップ表示（viの慣習に合わせる）
- `Tab` キーで候補を順に選択
- 候補数が多い場合は最大8件表示、スクロール可能

#### エラーメッセージ

```
├──────────────────────────────────────────────────────────────────────┤
│ E: Unknown command 'xyz'. Type :help for available commands. [Back]  │
└──────────────────────────────────────────────────────────────────────┘
```

- 不正コマンド実行時、コマンド入力行にエラーメッセージを2秒間表示
- エラーメッセージのスタイル: Red Bold
- 2秒後にノーマルモードに自動復帰

### 4.3 ヘルプモード (Help Mode)

`:help` コマンド実行で遷移。全画面オーバーレイとしてヘルプ画面を表示する。

#### レイアウト

```
┌──────────────────────────────────────────────────────────────────────┐
│                          mdir v0.2.0 - Help                          │  ← タイトル（中央揃え）
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  [セクション内容 - スクロール可能エリア]                                 │  ← コンテンツ領域
│                                                                      │
│                                                                      │
├──────────────────────────────────────────────────────────────────────┤
│ j/k:Scroll  q/Esc:Close                              Line 1/120     │  ← フッター
└──────────────────────────────────────────────────────────────────────┘
```

| 領域 | 高さ | 内容 |
|---|---|---|
| タイトル | 1行 | `mdir v<version> - Help`（中央揃え、Bold） |
| コンテンツ | H-3行 | ヘルプテキスト（スクロール可能） |
| フッター | 1行 | 操作ヒント + 現在行/総行数 |

#### コンテンツセクション構成

```
━━━ NAVIGATION (vi-style) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  h            Go to parent directory
  j / ↓        Move cursor down
  k / ↑        Move cursor up
  l / Enter    Enter directory / Open file
  g            Jump to top
  G            Jump to bottom
  ~            Go to home directory
  Tab          Switch active pane

━━━ FILE OPERATIONS ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  c / F5       Copy to opposite pane
  m / F6       Move to opposite pane
  d / F8       Delete (move to trash)
  r / F2       Rename
  n            Create new directory
  t            Create new file
  Space        Mark / Unmark file
  a            Select all / Deselect all
  s            Sort menu
  .            Toggle hidden files
  i            File info popup

━━━ COMMAND MODE ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Type ':' to enter command mode (like vi)

  :help [topic]    Show this help screen
  :q / :quit       Quit application
  :cd <path>       Change directory
  :sort <by>       Sort (name/size/date/ext)
  :set <option>    Change setting
  :!<command>      Execute shell command
  :mkdir <name>    Create directory
  :touch <name>    Create file
  :bookmark [n]    Add bookmark

  Press Esc or click [Back] to exit command mode.

━━━ MOUSE OPERATIONS ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Left click       Select file / Switch pane
  Double click     Enter directory / Open file
  Right click      Context menu
  Scroll wheel     Scroll file list
  Drag border      Resize panes

━━━ CONFIGURATION ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Config file:  ~/.config/mdir/config.toml
  See :help config for configuration details.
```

- セクション見出し: `━━━ <TITLE> ━━━` 形式（Cyan Bold）
- キー名: Bold White（固定幅16文字）
- 説明文: Normal White
- `:help <topic>` でトピック別表示時は該当セクションの先頭にジャンプ

#### ヘルプ内操作
| キー/操作 | 動作 |
|---|---|
| `j` / `↓` / スクロールダウン | 1行下にスクロール |
| `k` / `↑` / スクロールアップ | 1行上にスクロール |
| `d` / `PageDown` | 半ページ下にスクロール |
| `u` / `PageUp` | 半ページ上にスクロール |
| `g` | 先頭にジャンプ |
| `G` | 末尾にジャンプ |
| `q` / `Esc` | ヘルプを閉じてノーマルモードに戻る |

## 5. ダイアログ・ポップアップ仕様

### 5.1 確認ダイアログ (ConfirmDialog)

ファイル削除等の破壊的操作時に表示される。

```
┌─────────── Delete ────────────┐
│                                │
│  Delete "Cargo.toml"?         │
│  (File will be moved to Trash) │
│                                │
│      [Yes (y)]   [No (n)]     │
└────────────────────────────────┘
```

| 要素 | スタイル |
|---|---|
| タイトル | Bold Red |
| メッセージ | Normal White |
| 注釈 | Dim |
| `[Yes]` ボタン | アクティブ時: 反転Red |
| `[No]` ボタン | アクティブ時: 反転Green |

- 画面中央にオーバーレイ表示
- `y` / `Enter`（Yesフォーカス時）で実行、`n` / `Esc` でキャンセル
- **マウス:** ボタンクリックで操作
- デフォルトフォーカスは `[No]`（安全側）

### 5.2 入力ダイアログ (InputDialog)

リネーム、新規ディレクトリ作成等で使用。

```
┌─────────── Rename ────────────┐
│                                │
│  New name:                     │
│  ┌──────────────────────────┐ │
│  │ Cargo.toml█              │ │
│  └──────────────────────────┘ │
│                                │
│    [OK (Enter)]  [Cancel (Esc)]│
└────────────────────────────────┘
```

- 入力フィールドにファイル名の初期値をセット
- 拡張子の前にカーソルを配置（リネーム時）
- `Enter` で確定、`Esc` でキャンセル
- **マウス:** ボタンクリックで操作

### 5.3 ソートメニュー (SortMenu)

```
┌──── Sort by ─────┐
│ ● Name        ↑  │
│ ○ Size           │
│ ○ Date           │
│ ○ Extension      │
├──────────────────┤
│ Dirs first: [✓]  │
└──────────────────┘
```

- `j`/`k` で項目移動、`Enter`/`Space`で選択
- `↑`/`↓` アイコンで昇順/降順を表示、`Enter`で切り替え
- **マウス:** 各項目をクリックで選択

### 5.4 コンテキストメニュー (ContextMenu)

右クリック時にカーソル位置に表示。

```
┌───────────────────┐
│  Copy         c   │
│  Move         m   │
│  Delete       d   │
│  Rename       r   │
│ ───────────────── │
│  Info         i   │
└───────────────────┘
```

- カーソル位置に表示（画面端の場合は自動調整）
- `j`/`k` またはマウスホバーで項目移動
- `Enter`/クリックで実行、`Esc`/画面外クリックで閉じる
- 各項目の右側にショートカットキーを表示（Dim）

### 5.5 ファイル情報ポップアップ (FileInfoPopup)

`i` キーで表示。

```
┌──────────── File Info ─────────────┐
│                                     │
│  Name:        Cargo.toml           │
│  Type:        Regular file          │
│  Size:        512 bytes (512B)      │
│  Created:     2026-02-10 09:15:30  │
│  Modified:    2026-02-11 14:30:22  │
│  Accessed:    2026-02-11 15:00:01  │
│  Permissions: -rw-r--r--           │
│  Owner:       vahma:staff          │
│  Inode:       12345678             │
│                                     │
│              [Close (Esc)]          │
└─────────────────────────────────────┘
```

### 5.6 進捗ダイアログ (ProgressDialog)

大きなファイルのコピー/移動時に表示。

```
┌─────────── Copying ────────────┐
│                                 │
│  large_file.zip                │
│  ████████████░░░░░░░░  60%     │

│                                 │
│           [Cancel (Esc)]        │
```

- プログレスバー: Cyan `█` / DarkGray `░`
- `Esc` でキャンセル可能

## 7. マウスインタラクション詳細

### 7.1 クリック判定領域

| 領域 | 左クリック | ダブルクリック | 右クリック |
|---|---|---|---|
| ヘッダー (タブ) | タブ切り替え | — | — |
| パスバー | ペインアクティブ化 | — | — |
| ファイルペイン (項目) | カーソル移動+ペイン切り替え | ディレクトリ入る/ファイル開く | コンテキストメニュー |
| ファイルペイン (空白) | ペインアクティブ化 | — | コンテキストメニュー（ディレクトリ操作） |
| ペイン境界 | ドラッグ開始 | — | — |
| ステータスバー | — | — | — |
| ファンクションバー (ボタン) | 対応アクション実行 | — | — |
| コマンド行 `[Back]` | コマンドモード終了 | — | — |

### 7.2 ダブルクリック判定
- 同一位置での2回クリック間隔が **500ms以内** の場合にダブルクリックと判定
- 1回目のクリックでカーソル移動、2回目で実行

### 7.3 ドラッグ操作
- ペイン境界線（`x = W/2` 付近 ±1カラム）でマウスダウン → ドラッグ開始
- ドラッグ中はリアルタイムで境界位置を更新
- 最小ペイン幅（20カラム）を下回る位置へのドラッグは制限

### 7.4 スクロール
- マウスホイールアップ: カーソル3行上に移動
- マウスホイールダウン: カーソル3行下に移動
- カーソル位置のペインが対象（アクティブ/非アクティブ問わず）

## 9. アニメーション・トランジション

TUIアプリのため、アニメーションは最小限とする。

| 場面 | 動作 |
|---|---|
| ディレクトリ遷移 | 即時切り替え（アニメーションなし） |
| ダイアログ表示 | 即時表示（フェードなし） |
| エラーメッセージ | 表示 → 2秒後に自動消去 |
| プログレスバー | 16ms間隔で更新 |
| コンテキストメニュー | 即時表示 |

## 10. ターミナルリサイズ対応

| イベント | 対応 |
|---|---|
| 横幅の変更 | ペイン幅を比率を維持して再計算 |
| 高さの変更 | ファイルペイン領域のみ拡縮 |
| 最小サイズ以下 | 警告メッセージをオーバーレイ表示 |
| リサイズ中 | 即時リドロー（16ms debounce） |
