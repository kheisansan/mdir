# mdir - Mac用ファイルマネージャー 要件定義書

**プロジェクト名:** mdir (Mac Directory Manager)
**バージョン:** 0.1.0
**作成日:** 2026-02-11
**ステータス:** ドラフト

---

## 1. プロジェクト概要

### 1.1 背景
1990年代に韓国で広く使われたDOS用ファイルマネージャー「MDIR」にインスパイアされた、
macOS向けのターミナルベース（TUI）ファイルマネージャーを開発する。
viエディタに着想を得たキーボード操作を軸としつつ、マウス操作にも対応した
モダンかつ高速なファイル操作を実現するツールを目指す。

### 1.2 ビジョン
> **「viライクなキーボード操作を軸に、マウスも使えるモダンなファイル操作ツール」**

### 1.3 プロジェクトスコープ
- macOSで動作するネイティブバイナリ（ターミナルアプリケーション）
- ビルドして実行可能な単一バイナリを配布
- Homebrew経由でのインストールも将来的に対応

---

|---|---|

## 4. 機能要件

### 4.1 Phase 1 - MVP（最小実用プロダクト）

#### FR-001: 2ペインファイルブラウザ
- **概要:** 画面を左右2分割し、それぞれ独立したディレクトリを表示する
- **詳細:**
  - 左右ペインの独立したディレクトリナビゲーション
  - アクティブペインのハイライト表示
  - Tab/Shift+Tabでペイン切り替え
  - 各ペインにカレントパスを表示
  - ファイル/ディレクトリの一覧表示（名前、サイズ、更新日時、パーミッション）

#### FR-002: 基本ナビゲーション（viスタイル）
- **概要:** viエディタ準拠のキーボード操作でのディレクトリ移動・ファイル選択
- **詳細:**
  - `h` : 親ディレクトリに戻る（vi: 左移動）
  - `j` / `↓` : カーソルを下に移動（vi: 下移動）
  - `k` / `↑` : カーソルを上に移動（vi: 上移動）
  - `l` / `Enter` : ディレクトリに入る / ファイルを開く（vi: 右移動）
  - `g` で先頭、`G` で末尾にジャンプ（vi: gg / G準拠）
  - `~` でホームディレクトリに移動
  - `/` でパス直接入力による移動（vi: 検索との親和性）
- **設計思想:**
  - viに慣れたユーザーが直感的に操作できるキーバインドを最優先とする
  - hjklによるナビゲーションはアプリ全体の基本操作として統一する

#### FR-003: 基本ファイル操作
- **概要:** ファイルの基本的なCRUD操作
- **詳細:**
  - `c` / `F5` : ファイル/ディレクトリのコピー（対向ペインへ）
  - `m` / `F6` : ファイル/ディレクトリの移動（対向ペインへ）
  - `d` / `F8` / `Delete` : ファイル/ディレクトリの削除（確認ダイアログ付き）
  - `r` / `F2` : リネーム
  - `n` : 新規ディレクトリ作成
  - `t` : 新規ファイル作成
  - 操作前の確認プロンプト（破壊的操作時）
  - 進捗表示（大きなファイル操作時）

#### FR-004: ファイル選択（マーキング）
- **概要:** 複数ファイルの選択と一括操作
- **詳細:**
  - `Space` で個別ファイルのマーク/アンマーク
  - `a` で全選択/全解除のトグル
  - マーク済みファイルの視覚的区別（色・アイコン）
  - マーク済みファイルに対する一括コピー/移動/削除

#### FR-005: ファイル情報表示
- **概要:** ファイルのメタ情報を確認
- **詳細:**
  - 画面下部のステータスバーに選択中ファイルの情報を表示
  - `i` でファイル詳細情報のポップアップ表示
    - ファイルサイズ、作成日時、更新日時、パーミッション
    - シンボリックリンクの参照先
    - ディレクトリの場合は中のファイル数

#### FR-006: ソート機能
- **概要:** ファイル一覧のソート
- **詳細:**
  - `s` でソートメニュー表示
  - ソート基準: 名前 / サイズ / 更新日時 / 拡張子
  - 昇順/降順の切り替え
  - ディレクトリを常に先頭に表示するオプション

#### FR-007: 隠しファイル表示切替
- **概要:** ドットファイルの表示/非表示
- **詳細:**
  - `.` (ドット) キーで隠しファイルの表示/非表示を切り替え
  - デフォルトは非表示（設定で変更可能）

#### FR-008: マウス操作対応
- **概要:** キーボード操作に加え、マウスによるモダンな操作も全面サポートする
- **詳細:**
  - **クリック操作:**
    - ファイル/ディレクトリをクリックでカーソル移動・選択
    - ダブルクリックでディレクトリに入る / ファイルを開く
    - ペインをクリックでアクティブペイン切り替え
    - ヘッダーのタブをクリックでタブ切り替え
    - ファンクションバーのボタンをクリックで各操作実行
    - コマンドモード中の `[Back]` テキストをクリックでコマンドモード終了
  - **右クリック（コンテキストメニュー）:**
    - ファイル/ディレクトリを右クリックでコンテキストメニュー表示
    - メニュー項目: コピー / 移動 / 削除 / リネーム / 情報表示
  - **スクロール:**
    - マウスホイールでファイル一覧のスクロール
  - **ドラッグ操作:**
    - ペイン境界のドラッグでペイン幅の調整
  - **設計思想:**
    - キーボード操作が主軸だが、マウスでも同等の操作が可能
    - マウスオンリーのユーザーでもストレスなく使える設計

#### FR-009: コマンドモード（viスタイル）
- **概要:** viエディタと同様に `:` キーでコマンドラインモードに入り、各種コマンドを実行する
- **詳細:**
  - **コマンドモードの開始:**
    - `:` キーを押すと画面最下部にコマンド入力行が表示される
    - プロンプトは `:` で始まり、viエディタと同じ見た目・操作感とする
  - **コマンドモードの終了:**
    - `Esc` キーでコマンドモードをキャンセルして通常モードに戻る
    - マウスで画面上の `[Back]` テキストをクリックしても通常モードに戻る
    - `Enter` でコマンドを実行した後も通常モードに戻る
  - **必須ビルトインコマンド:**
    - `:help` — アプリの使用方法・全キーバインド・コマンド一覧を表示するヘルプ画面を開く
    - `:q` / `:quit` — アプリを終了する
    - `:cd <path>` — 指定パスへ移動する
    - `:sort <criteria>` — ソート基準を変更する（name / size / date / ext）
    - `:set <option>` — 設定値を変更する（例: `:set hidden` で隠しファイル表示）
    - `:!<command>` — シェルコマンドをカレントディレクトリで実行する
    - `:mkdir <name>` — 新規ディレクトリを作成する
    - `:touch <name>` — 新規ファイルを作成する
    - `:bookmark [name]` — カレントディレクトリをブックマークに追加する
  - **コマンド入力支援:**
    - `Tab` キーでコマンド名・パスのオートコンプリート
    - `↑` / `↓` でコマンド履歴の参照
    - 不正なコマンド入力時のエラーメッセージ表示
  - **`:help` コマンドの詳細仕様:**
    - 全画面ヘルプ画面を表示する
    - 以下のセクションを含む:
      1. アプリ概要とバージョン情報
      2. ノーマルモードのキーバインド一覧
      3. コマンドモードで使えるコマンド一覧と使い方
      4. マウス操作の説明
      5. 設定ファイルの場所と書き方
    - ヘルプ画面内は `j`/`k` でスクロール、`q` または `Esc` で閉じる
    - `:help <topic>` でトピック別ヘルプも表示可能（例: `:help copy`, `:help keybindings`）

### 4.2 Phase 2 - 拡張機能

#### FR-010: クイック検索・フィルタ
- **概要:** 現在のディレクトリ内でのインクリメンタルサーチ
- **詳細:**
  - `f` でフィルタモード開始
  - 入力に応じてリアルタイムで絞り込み
  - ワイルドカード（`*`, `?`）対応
  - `Esc` でフィルタ解除

#### FR-011: ファイルプレビュー
- **概要:** ファイル内容のクイックプレビュー
- **詳細:**
  - `p` でプレビューパネルのトグル（3ペイン表示）
  - テキストファイル: シンタックスハイライト付きプレビュー
  - 画像ファイル: ターミナル内でのASCIIアート/Sixelプレビュー
  - バイナリファイル: hexダンプ表示
  - ディレクトリ: ツリー表示

#### FR-012: ブックマーク機能
- **概要:** よく使うディレクトリへのクイックアクセス
- **詳細:**
  - `b` でブックマーク一覧表示
  - `B` でカレントディレクトリをブックマーク追加
  - `1`-`9` の数字キーでブックマークへジャンプ
  - ブックマークは設定ファイルに永続化

#### FR-013: ディスク使用量表示
- **概要:** ディレクトリのサイズ解析
- **詳細:**
  - `D` でカレントディレクトリのサイズ解析開始
  - 各サブディレクトリのサイズをバー表示
  - バックグラウンドでの非同期計算

---

### 4.3 Phase 3 - 高度な機能

#### FR-014: 高度な検索（grep的）
- **概要:** ファイル内容を含む再帰的検索
- **詳細:**
  - `Ctrl+f` でグローバル検索モード
  - ファイル名検索（再帰的）
  - ファイル内容検索（ripgrep連携）
  - 検索結果一覧からのジャンプ

#### FR-015: 圧縮・アーカイブ対応
- **概要:** アーカイブファイルの閲覧・操作
- **詳細:**
  - `.zip`, `.tar.gz`, `.tar.bz2`, `.7z` の内容一覧表示
  - アーカイブ内のファイルプレビュー
  - 選択ファイルの圧縮・解凍

#### FR-016: Git統合
- **概要:** Gitリポジトリ情報の表示
- **詳細:**
  - ファイル一覧にGitステータスアイコン表示（modified, untracked, staged等）
  - 現在のブランチ名をヘッダーに表示
  - `.gitignore`されたファイルの視覚的区別

#### FR-017: タブ機能
- **概要:** 複数のワークスペースを切り替え
- **詳細:**
  - `Ctrl+t` で新規タブ作成
  - `Ctrl+w` でタブを閉じる
  - `Ctrl+←/→` または数字キーでタブ切り替え
  - 各タブが独立した2ペイン構成を持つ

## 5. 非機能要件

### NFR-001: パフォーマンス
| 指標 | 目標値 |
|---|---|
| 起動時間 | 100ms以下 |
| ディレクトリ表示（1,000ファイル） | 50ms以下 |
| ディレクトリ表示（10,000ファイル） | 200ms以下 |
| ファイル操作のUI応答性 | 16ms以下（60fps） |
| メモリ使用量（通常時） | 50MB以下 |
| バイナリサイズ | 20MB以下 |

### NFR-002: 互換性
- macOS 13 (Ventura) 以降をサポート
- Apple Silicon (M1/M2/M3/M4) および Intel Mac 両対応
- Terminal.app, iTerm2, Alacritty, WezTerm, Ghostty で動作確認
- 256色 / TrueColor 対応（グレースフルデグラデーション）

### NFR-003: 安全性
- 削除操作は必ず確認ダイアログを表示
- ゴミ箱への移動をデフォルトとする（macOSのTrash連携）
- 権限のないファイルへの操作時に明確なエラーメッセージ
- クラッシュ時にターミナル状態を確実に復元

### NFR-004: ユーザビリティ
- 初回起動時に `:help` コマンドの存在を案内するウェルカムメッセージを表示
- `:help` コマンドで全操作方法・キーバインド・コマンド一覧をいつでも参照可能
- viエディタ経験者が違和感なく操作できるキーバインド設計
- マウスのみでも基本的な全操作が可能（キーボードが使えない状況への対応）
- カラーテーマのカスタマイズ対応

### NFR-005: 設定・カスタマイズ
- 設定ファイル: `~/.config/mdir/config.toml`
- キーバインドの完全カスタマイズ
- カラースキームの定義
- デフォルトソート順、隠しファイル表示等の設定

### 6.2 アプリケーションモード遷移

viエディタのモード概念に準拠し、以下の3つのモードを持つ。

```
                    ':'キー入力
  ┌──────────┐ ──────────────────► ┌──────────────┐
  │          │                      │              │
  │ Normal   │ ◄────────────────── │  Command     │
  │ Mode     │   Esc / [Back]click │  Mode        │
  │          │   / Enter(実行後)    │              │
  │ (通常操作)│                      │ (':'プロンプト) │
  └──────────┘                      └──────────────┘
       │                                   │
       │ ':help' 実行                       │ ':help' 入力+Enter
       │ ──────────────────────────────── │
       │                                   │
       ▼                                   ▼
  ┌──────────────┐
  │              │
  │  Help        │
  │  Mode        │
  │              │
  │ (ヘルプ画面)   │
  └──────────────┘
       │
       │ 'q' / Esc で閉じる
       │
       ▼
  ┌──────────┐
  │ Normal   │
  │ Mode     │
  └──────────┘
```

| モード | 説明 | 入り方 | 出方 |
|---|---|---|---|
| **Normal** | ファイルブラウジング・操作を行う通常モード | 起動時 / 他モードから戻る | `:` でCommand、`:help` でHelp |
| **Command** | viの `:` コマンドライン。画面最下部にプロンプト表示 | `:` キー入力 | `Esc` / `[Back]`クリック / `Enter` |
| **Help** | アプリ使用方法の全画面ヘルプ表示 | `:help` コマンド実行 | `q` / `Esc` |

## 7. プロジェクト構造

```
dirtools/
├── Cargo.toml                  # プロジェクト設定・依存関係
├── Cargo.lock
```

## 10. リスク分析

| リスク | 影響度 | 発生確率 | 対策 |
|---|---|---|---|
| ターミナル互換性問題 | 高 | 中 | crossterm採用、主要ターミナルでの早期テスト |
| 大量ファイル時のパフォーマンス | 高 | 中 | 仮想スクロール実装、遅延読み込み |
| macOS固有API対応 | 中 | 中 | trashクレートなど既存ライブラリの活用 |
| キーバインドの衝突 | 低 | 高 | カスタマイズ可能なキーバインド設計 |
| ファイル操作の安全性 | 高 | 低 | 確認ダイアログ、ゴミ箱デフォルト使用 |

## 12. 補足: キーバインド・操作一覧（Phase 1）

### 12.1 ノーマルモード（キーボード）

| キー | 動作 | viとの対応 |
|---|---|---|
| `h` | 親ディレクトリへ | vi: 左移動 |
| `j` / `↓` | カーソルを下に移動 | vi: 下移動 |
| `k` / `↑` | カーソルを上に移動 | vi: 上移動 |
| `l` / `Enter` | ディレクトリに入る / ファイルを開く | vi: 右移動 |
| `g` | 先頭にジャンプ | vi: gg |
| `G` | 末尾にジャンプ | vi: G |
| `Tab` | ペイン切り替え | — |
| `Space` | ファイルをマーク/アンマーク | — |
| `a` | 全選択/全解除 | — |
| `c` / `F5` | コピー | — |
| `m` / `F6` | 移動 | — |
| `d` / `F8` | 削除 | — |
| `r` / `F2` | リネーム | — |
| `n` | 新規ディレクトリ作成 | — |
| `t` | 新規ファイル作成 | — |
| `s` | ソートメニュー | — |
| `.` | 隠しファイル表示切替 | — |
| `i` | ファイル情報表示 | — |
| `~` | ホームディレクトリへ | — |
| `/` | パス入力 | vi: 検索 |
| `:` | **コマンドモードに入る** | vi: コマンドモード |
| `q` | 終了 | vi: :q |

### 12.2 コマンドモード（`:` 入力後）

| 操作 | 動作 |
|---|---|
| `Enter` | コマンドを実行し、ノーマルモードに戻る |
| `Esc` | コマンドをキャンセルし、ノーマルモードに戻る |
| `[Back]` クリック | コマンドをキャンセルし、ノーマルモードに戻る（マウス） |
| `Tab` | オートコンプリート |
| `↑` / `↓` | コマンド履歴を辿る |

### 12.3 ビルトインコマンド一覧

| コマンド | 動作 |
|---|---|
| `:help [topic]` | **ヘルプ画面を表示**（必須コマンド） |
| `:q` / `:quit` | アプリを終了 |
| `:cd <path>` | 指定パスに移動 |
| `:sort <criteria>` | ソート変更（name / size / date / ext） |
| `:set <option>` | 設定変更（例: `:set hidden`） |
| `:!<command>` | シェルコマンド実行 |
| `:mkdir <name>` | ディレクトリ作成 |
| `:touch <name>` | ファイル作成 |
| `:bookmark [name]` | ブックマーク追加 |

### 12.4 マウス操作

| 操作 | 動作 |
|---|---|
| 左クリック | ファイル選択 / ペイン切り替え / タブ切り替え |
| ダブルクリック | ディレクトリに入る / ファイルを開く |
| 右クリック | コンテキストメニュー表示 |
| スクロールホイール | ファイル一覧のスクロール |
| ペイン境界ドラッグ | ペイン幅の調整 |
| `[Back]` クリック | コマンドモードを終了 |
| ファンクションバークリック | 各機能の実行 |
